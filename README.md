# আমাদের পাঠশালা · Amader Pathshala

বাংলায় কথা বলা শিক্ষণ অ্যাপ — **টুনি** প্রতিটি শিশুকে নাম ধরে ডাকে ("হে ফারিহা! মনোযোগ দিয়ে শোনো…")।
Free, offline, ad-free PWA. No server, no account, no data leaves the phone.

## 📖 পাঠ্যবই (NCTB পিডিএফ)
"পাঠ্যবই" বোতামে অফিসিয়াল সাইটের লিংক আছে। বই নামিয়ে "পিডিএফ বই যোগ করুন" দিয়ে অ্যাপে রাখলে ফোনেই সংরক্ষিত হয় এবং **ইন্টারনেট ছাড়া** পড়া যায় (পাতা উল্টানো/সোয়াইপ, জুম, শেষ পাতা মনে রাখা)। পিডিএফ রিডার pdf.js (Apache-2.0, `lib/` ফোল্ডারে) — তাই `lib/` আপলোড করতে ভুলবেন না।

## টুনির ডাক (আগ্রহ ধরে রাখা)
- **ডাক-রিমাইন্ডার:** অভিভাবক প্যানেলে দুটি সময় ঠিক করলে অ্যাপ খোলা থাকলে টুনি কথা বলে সবাইকে নাম ধরে ডাকে (যাদের আজকের চ্যালেঞ্জ বাকি)।
- **নিষ্ক্রিয় ডাক:** কেউ ফোনে হাত না দিলে টুনি নাম ধরে ডাকে ("ফারিহা, আমি এখানেই আছি!")।
- **নোটিফিকেশন:** অনুমতি দিলে ফোনে নোটিফিকেশনও আসে। অ্যাপ বন্ধ থাকলে শুধু Chrome-এ ইনস্টল করা অ্যাপে, Periodic Background Sync দিয়ে, কয়েক ঘণ্টা পরপর — সময়ের গ্যারান্টি নেই। নিশ্চিত সময়ের জন্য ফোনের অ্যালার্ম দিন। সার্ভার-পুশ (সঠিক সময়) চাইলে আলাদা ব্যাকএন্ড লাগবে।

## সৎ সীমাবদ্ধতা
- টুনির কণ্ঠ ফোনের **বাংলা টেক্সট-টু-স্পিচ ভয়েসের** ওপর নির্ভর করে (Android: Settings → Language → Text-to-speech → Google → Bangla ভয়েস ডেটা)। না থাকলে লেখা দেখা যায়, কথা নয়।
- "বলে উত্তর" মাইক (Chrome Speech Recognition) ইন্টারনেট লাগে, নিখুঁত নয়; তাই সবখানে বোতামও আছে।
- টুনি নির্ধারিত প্রশ্নোত্তর করে — মুক্ত AI চ্যাট নয়।
- প্রশ্নগুলো নিজের ভাষায় লেখা (পাঠ্যবইয়ের হুবহু নয়); ক্লাস ৪ অংশ আনুমানিক — স্কুলের বই/শিক্ষকের সাথে মিলিয়ে নিন।
- কুরআনের আয়াত/সুর নেই; শুদ্ধ তিলাওয়াত উস্তাদের কাছে শেখানো উচিত। ছড়া-গল্প সবই এই অ্যাপের জন্য নতুন লেখা।

## GitHub Pages-এ চালু করা
1. নতুন repo (যেমন `amader-pathshala`) বানিয়ে এই ফোল্ডারের সব ফাইল আপলোড করুন (`.github`, `.nojekyll` সহ)।
2. Settings → Pages → Source: **GitHub Actions** (বা Deploy from branch → main / root)।
3. লিংক: `https://<username>.github.io/amader-pathshala/` — Chrome-এ খুলে ⋮ → *Add to Home screen / Install app*।

> প্রতিটি অ্যাপের জন্য আলাদা repo রাখুন, নইলে Chrome "already installed" দেখাতে পারে। ডেটা ব্রাউজারে থাকে — মাঝে মাঝে **ব্যাকআপ** নিন।

## ইনস্টল না হলে
অ্যাপের ভেতরে হোম পেজের **"📲 ফোনে ইনস্টল করবেন কীভাবে?"** বোতামে চাপলে স্বয়ংক্রিয় পরীক্ষা (ফাইল, https, Chrome, অফলাইন সার্ভিস) ও ধাপ দেখাবে।
সবচেয়ে সাধারণ কারণ: জিপ খুলে **বাইরের ফোল্ডারসহ** আপলোড করা — repo-র root-এ সরাসরি `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` থাকতে হবে। এছাড়া WhatsApp/Facebook-এর ভেতরের ব্রাউজারে খুললে ইনস্টল আসে না — Chrome-এ খুলুন। পুরোনো অ্যাপ থাকলে `chrome://webapks` থেকে আনইনস্টল করুন।

## আপডেট দেখা যাচ্ছে না?
GitHub-এ ফাইল বদলে ১–২ মিনিট অপেক্ষা করুন (repo-র Actions ট্যাবে সবুজ ✔ দেখুন)। অ্যাপের হোম পেজের নিচে **সংস্করণ** লেখা আছে; পুরোনো দেখালে **"🔄 নতুন সংস্করণ লোড করুন"** চাপুন।

## "This app cannot be installed" দেখালে
কারণ প্রায় সবসময় repo-তে `manifest.webmanifest` বা `icons/` ফোল্ডার আপলোড হয়নি। এই সংস্করণে `index.html`-এর ভেতরেই ইনস্টলের তথ্য ও আইকন বসানো আছে — ফাইল না থাকলেও নিজে থেকে ঠিক করে নেয়। তবু সব ফাইল আপলোড করাই ভালো।
